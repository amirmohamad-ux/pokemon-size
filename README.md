# Pokemon CLI Finder

A lightweight, modular command-line tool built with Python to fetch and explore Pokemon data directly from the PokeAPI.

## Features

- **Fetch Pokemon List**: Easily retrieve a list of Pokemon from the PokeAPI.
- **Detailed Insights**: View specific attributes of your selected Pokemon.
- **Color-Coded Output**: Enhanced terminal experience using `colorama` for better readability.
- **Robust Error Handling**: Implements `try-except` blocks and `raise_for_status()` to manage network issues and API errors gracefully.
- **Modular Design**: Organized functions for better maintenance and scalability.

## Prerequisites

- Python 3.x
- `requests` library
- `colorama` library
